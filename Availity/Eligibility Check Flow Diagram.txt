ERROR HANDLING:
================
┌───────────────────────────────────────────────────────────────────────────────────────── ───┐
│  Exception Type                │  Handler Location                │  Action                 │
├────────────────────────────────┼──────────────────────────────────┼─────────────────────────┤
│  KeyNotFoundException          │  EligibilityCheckEngineService   │  Throw (404)            │
│  (Encounter/Coverage not found)│                                  │                         │
├────────────────────────────────┼──────────────────────────────────┼─────────────────────────┤
│  OperationCanceledException    │  EligibilityCheckEngineService   │  Mark check as Failed   │
│  (Timeout)                     │                                  │  with "timed out"       │
│                                │                                  │  Then re-throw          │
├────────────────────────────────┼──────────────────────────────────┼─────────────────────────┤
│  HttpRequestException          │  Polly Retry Handler             │  Retry 3x with backoff  │
│  (Network/API error)           │  → EligibilityCheckEngineService │  If still fails:        │
│                                │                                  │  Mark check as Failed   │
│                                │                                  │  with ex.Message        │
├────────────────────────────────┼──────────────────────────────────┼─────────────────────────┤
│  Any other Exception           │  EligibilityCheckEngineService   │  Mark check as Failed   │
│                                │                                  │  with ex.Message        │
│                                │                                  │  Then re-throw          │
