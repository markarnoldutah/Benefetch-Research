# New Encounter (Patient Checkin)

## Patient 
- input fields
- buttons:  Search, Create

### Create
- proceed to patient confirmation card (patientId null)

### Search 
- 1 result found > goto patient confirmation card 
- +1 results found > display table for selection > goto patient confirmation card
- No results found --> proceed to patient confirmation card (patientId null)

## Encounter Details
- input fields

## Coverage Enrollments
- display existing coverages with edit or archive buttons
- button:  add another coverage

## Eligibility Checks
- display coverages plans with checkboxes to indicate check needed

## Button:  Save and Run Eligibility Checks
